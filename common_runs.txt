You can use the following commands in your SSH terminal to monitor memory and CPU usage:

- `top`
  Shows real-time CPU and memory usage for all processes.

- `htop`
  An enhanced version of `top` (if installed). Use arrow keys to navigate.

- `free -h`
  Displays total, used, and free memory.

- `vmstat 1`
  Shows system performance statistics, updated every second.

- `ps aux --sort=-%mem | head`
  Lists top processes by memory usage.

- `ps aux --sort=-%cpu | head`
  Lists top processes by CPU usage.

You can run these commands directly in your SSH terminal.
